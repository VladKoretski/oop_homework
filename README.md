# OOP Homework: Наследование, инкапсуляция и полиморфизм

Данный проект реализует систему учета оценок студентов и лекторов в рамках учебного процесса на языке Python.  
Проект демонстрирует принципы объектно-ориентированного программирования: наследование, инкапсуляцию и полиморфизм.

## Описание классов

- **`Mentor`** – родительский класс для всех наставников. Хранит имя, фамилию и список курсов, к которым прикреплён наставник.
- **`Lecturer`** (наследует `Mentor`) – лектор. Получает оценки от студентов за проведённые лекции. Умеет вычислять среднюю оценку и сравниваться с другими лекторами по этому показателю.
- **`Reviewer`** (наследует `Mentor`) – проверяющий (эксперт). Выставляет оценки студентам за домашние задания по закреплённым курсам.
- **`Student`** – студент. Может оценивать лекторов, получать оценки от проверяющих, хранит список завершённых и текущих курсов.

Для всех классов перегружен магический метод `__str__`, а для `Lecturer` и `Student` реализованы операторы сравнения (`>`, `<`, `==`) на основе средней оценки.

## Требования

- Python 3.9 или выше
- `pytest` (для запуска тестов)

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_вашего_репозитория>
   cd oop_homework
   ```

2. Установите зависимости (опционально, если планируете запускать тесты):
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите демонстрационный скрипт «Полевые испытания»:
   ```bash
   python main.py
   ```

## Тестирование

Для запуска всех тестов выполните в корневой папке проекта:

```bash
pytest -v
```

Для проверки покрытия кода тестами (требуется `pytest-cov`):
```bash
pytest --cov=src/oop_homework
```

## Непрерывная интеграция (CI)

В проекте настроен GitHub Actions. При каждом `push` или `pull request` в ветку `main` автоматически:
- устанавливается Python (версии 3.9, 3.10, 3.11);
- устанавливаются зависимости из `requirements.txt`;
- запускаются все тесты с помощью `pytest`.

Статус сборки можно увидеть на вкладке `Actions` вашего репозитория.
